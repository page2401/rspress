# 嵌套子页 B：多级子目录与侧边栏同步机制

Rspress 采用分散式 `_meta.json` 约定：在 `docs/04-directory/_meta.json` 中将子目录 `nested` 声明为 `{ "type": "dir", "name": "nested", "label": "嵌套子目录实测 (_meta.json)" }`，即可为英文目录名指定清晰的中文侧边栏分组，相比集中手写整棵侧边栏树更易多人协作维护。
